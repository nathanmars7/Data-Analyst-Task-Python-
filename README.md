# Data analyst task: trip SQL in Python

> **Archived learning exercise (2022).** Kept as-is; not maintained and not part of the current portfolio.

A take-home style exercise (`Data Analyst Python Task 1 .ipynb`): load trip data into an in-memory SQLite database from Python, answer questions with SQL through `sqlite3`, and tidy the results in pandas. The notebook's second section holds working notes.

## Run it

Open the notebook in Jupyter with `pandas` and `numpy` installed; `sqlite3` is in the standard library. The input data is not included in the repo.
